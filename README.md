## 先分清：你要的是“虚拟主机”还是 VPS

搜这个关键词时你会发现，排在前面的大部分文章其实都在讲 VPS。这是两个不同的产品，搜的人经常混着找。

虚拟主机（共享主机）给的是一个 cPanel 面板环境：登录后台、一键装 WordPress、传文件、建数据库，网站就能跑。你不用碰命令行，服务商替你管服务器。适合个人博客、展示站、小型企业官网。
